# AnimalMatcher API

Una API inteligente diseñada para analizar características físicas ingresadas por el usuario y determinar qué animal coincide o comparte dichos rasgos. 

##  Características

- **Análisis de Rasgos:** Recibe un conjunto de características físicas (ej. tipo de pelaje, extremidades, hábitat, color, tamaño) y procesa la coincidencia.
- **Respuesta JSON Estructurada:** Devuelve el animal más afín junto con un porcentaje de compatibilidad y una breve descripción.

---

##  Tecnologías Utilizadas

- **Lenguaje:** Python 
- **Procesamiento:** Lógica de coincidencia basada en pesos o embeddings vectoriales.
